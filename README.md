# Ross Wardrup

I'm a GIS developer in Colorado. My day job is contract work on FEMA's Hazus platform for the Risk MAP program. I'm also finishing an MPH in epidemiology at the University of Memphis, where my thesis models West Nile virus risk from mosquito surveillance data. I'm hoping to start a PhD in spatial epidemiology next.

## What I'm working on

- **MESA** (Mapping Epidemiology for Sparse Areas) is geostatistical software for small-area disease mapping. It does Gi* hot-spot detection and empirical Bayes rate smoothing in a node-based workflow. I use it for my West Nile work, and a small health department in Utah uses it too. [spatialepi.org](https://spatialepi.org)
- **axterm** is a packet radio terminal. I run it on my Mac, iPad and iPhone for AX.25 packet and Winlink.
- **Timbra** is a macOS logbook for home recording. It keeps track of releases, sessions and signal chains, and it measures loudness and tone across an album so you can see which tracks don't sit with the rest.
- **Practice Room** is a web app for logging music practice, repertoire, lessons and gigs.

## Older projects

Most of my pinned repos are older C++/Qt and Python tools:

- **BuzzBot** tracks drinks you've tried. C++/Qt, runs on Linux, macOS and Windows.
- **GIS-Helper** puts a GUI on the raster and vector chores I got tired of scripting by hand.
- **CF_Tool** is a set of C++ utilities for config files and structured data.
- **Ownly** keeps an inventory of the stuff you own.
- **MiniHamLog** is a small ham radio logbook that stays out of your way while you operate.

I mostly write C++ (usually with Qt) and Python. The web projects are React and Node on PostgreSQL.
